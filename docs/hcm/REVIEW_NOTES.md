# Implementation Review Notes

Code-level findings surfaced by the documentation pass (independent agents reading each branch's code against the manual). These are issues in OUR implementation, distinct from the book discrepancies in VERIFICATION.md. Grouped by severity; branch in parentheses. None are fixed yet — each PR body lists its branch's items as a review checklist.

## Likely bugs (recommend fixing before or during branch review)

1. ~~FIXED (feat/hcm-ch15-review-fixes)~~ **PyO3 `SubSegment` docstring says length is in miles; the engine treats it as feet** (÷5280). A Python caller following the docstring gets a 5,280x error. This is the historical Ch 15 unit footgun, now printed in the bindings docs. `src/copython/chapter15.rs` (feat/hcm-restructure).
2. ~~FIXED (fix/hcm-ch12-pce-tables)~~ **`todo!()` panics reachable in `adjustment_heavy_vehicle_factor`** for grade/length PCE combos outside the transcribed grid, and its `length == 0.125` fallback clobbers previously computed `e_t`. Library code should never panic on valid-ish input. `src/hcm/chapter12/basicfreeways.rs` (feat/hcm-ch12-14-completion). **The review that fixed this found the transcription itself was far worse than the panic**: `ET_TABLE_30SUT`, `ET_TABLE_50SUT`, and `ET_TABLE_70SUT` were byte-identical to one another and held (mostly) Exhibit 12-28, so 30% and 50% SUT analyses silently used 70%-SUT PCEs; only 1 of 192 entries in the nominal 30% table matched Exhibit 12-26. The `p_t >= 0.25` match arms were separately wrong (12/24 entries for the 50% mix, 6/24 for the 70%). Grades 3.5-6% were missing from both paths entirely. All three tables are now generated from the EPUB by `scripts/gen_pce_table.py`, cover all eight printed grades, interpolate as the exhibits permit, and return errors off-domain; `tests/test_pce_table_epub.py` re-derives the module from the EPUB and diffs it byte for byte. Note it **skips in CI**: `resources/` is gitignored (copyrighted), so it is a local pre-commit guard, not an enforced gate.
